Project Description.

SCPA-Downloads/Special contains databases, utility shells, and files that support "special" downloads of SCPA data. These downloads may be single streets or entire areas that need unique treatment because of the layout of the publisher territories.

The databases themselves have a dedicated management project SpecialSCdb that is used whenever publisher territories need unique treatment. That project "builds" and updates any of the /Special databases. SpecialSCdb

The /Special folder serves as sort of a "central clearing house" for all territories that need unique treatment. Some territories may need to use the data from more than one special database. A special database may also need to be used for several territories. The supporting shells and files within the /Special folder provide a standardized method that allows for coordinating which territory(ies) need to be updated when a special database is updated.

For example, suppose a street is long enough so that is crosses publisher territory boundaries. Suppose further, that the territory boundary that crosses this street is in the middle of a "block" (like in condominium complexes). The /Special download will include all addresses along the street, but the territories will only include their subset of the street addresses. The /Special databases and supporting files make this situation quite manageable.

Whenever the /Special database for the street is updated with a fresh download, all territories using that street will need to be updated as well. In turn, whenever the SCPA master data is updated for the entire congregation territory, the /Special database for the street will need to be updated with the newest SCPA data from the master.
